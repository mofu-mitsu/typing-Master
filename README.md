# Typing Master (実務データ入力演習ソフト)

就労移行支援や事務職スキル向上のための、実践的なデータ入力・タイピング練習アプリケーションです。
ビジネス文書作成からチャット対応・キャラクター対話まで、実務に近い形式でトレーニングできます。

## 概要

- **フレームワーク**: React 19 + TypeScript + Vite
- **スタイル**: 原作デザイン完全踏襲（一般企業実務コース / 教育機関とりの丘学園実習コース）
- **機能**:
  - 研修コース選択（一般企業 実務コース / 教育機関 とりの丘実習コース）
  - とりの丘学園実習詳細業務（名簿データ登録、先生の指示・業務連絡、生徒チャット対応、生徒からの依頼、グループチャット、総合実務）
  - クラス絞り込み（全校、1-1、1-2、1-4、2-1、2-2、3-1、3-2、教職員）
  - 課題数選択（5問、10問、20問）
  - スペースキーによる演習開始
  - 柔軟なローマ字入力判定（shi/si, chi/ti, tsu/tu, fu/hu, ji/zi, sha/sya, cha/tya, ja/zya 等）
  - リアルタイム入力ガイド＆キーボードハイライト（ミスキーのフラッシュアニメーション）
  - キャラクタ表情差分切り替え（通常 / ミス時 / 正解時 / 好感度高時）
  - 効果音（正解・ミス・業務完了クリア音、音量ON/OFFトグル）
  - 詳細スコアリング（WPM・正解数・ミス数によるスコア、S〜Dランク判定、苦手キー分析）
  - ローカルストレージによる自己ベスト保存およびキャラ好感度（親愛度）蓄積

## 開発環境の起動

```bash
npm run dev
```

## ビルド

```bash
npm run build
```
